**Goal:** Make every colony recognisable from afar, and make colonies' scents compete per cell. Merge into main so Marek's desktop icon runs it, but only after the user approves the merge.

## What Marek reported (testing M1.6 on a five-colony map)

1. Ants need much more of their colony's colour.
2. Every trail is teal or yellow, whatever the colony, so he can't tell colonies apart from afar. He asked where the yellow comes from.
3. Colony A's scent has no effect on colony B. He wants the scents on one grid cell to interact, weighted by how much each colony uses it, so a cell can eventually flip to the colony that walks there more.

## What Claude found

- The default trail view is `HeatmapMode.DualChannel` (`src/render/view_settings.ts`). Teal means "way home" and amber/yellow means "way to food", summed over every colony, so all colonies look identical. That's where the yellow comes from.
- `HeatmapMode.ColonyColor` exists (M key or Settings), but:
  - it shows only the owner's colour, with no way-home/way-to-food distinction;
  - BUG: `fillHeatmapRgba` calls `colonyHex(owner)` with the colony *id*, while ants and nests use `colony.color`, the palette index the player picked. A colony that picked Azure but has id 0 draws Ember trails.
- `paintAnt` (`src/render/sprite_atlas.ts`) draws a brown body (`kAntBase`). The colony colour is only a 3 px gaster band and a faint thorax sheen.
- The nest ring is thin: `lineWidth r × 0.07`, alpha 0.7.
- Scent: there's one layer per colony. With `territoryRule` on, `deposit` multiplies rival layers at the cell by `(1 − strength × foreignErasureFactor)`. `owner` is a plain argmax, used only for drawing. Sensing reads only the ant's own layer, so a rival's scent never changes what an ant does.

## Task 1: trails in colony colours (the new default view)

- Fix the bug. `fillHeatmapRgba` receives the colonies' palette indices (`colorByColony: readonly number[]`, from `world.colonies[i].color`) and never indexes the palette by colony id.
- Views:
  - the default becomes `ColonyColor`, labelled "Colonies";
  - `DualChannel` stays, labelled "Trail type";
  - M cycles Colonies → Trail type → Off.
- Run-HUD legend:
  - Colonies mode: one swatch per colony (its name and colour), plus "bright = way to food · dim = way home";
  - Trail type mode: the existing teal/amber legend.
- Colour rule, per cell:
  - `a` = owner (with Task 4's hysteresis); `sa` = max(home_a, food_a).
  - `sb` = the strongest other colony's max(home, food), or 0.
  - `total` = the sum over all colonies of max(home, food).
  - `base` = trailHex(palette index of a)
  - `typeShare` = food_a / (home_a + food_a)
  - `rgb` = base × (0.6 + 0.4 × typeShare). Food trails are bright and home trails dimmer, in the same hue.
  - `contest` = sa > 0 ? sb / sa : 0
  - `rgb` = mix(rgb, grey(luma(rgb)), 0.55 × contest). Contested ground loses saturation. Never mix hues: red plus green would read as a fake Gold colony.
  - `alpha` = 255 × heatAlpha × min(1, sqrt(total))
- Trail colours are luminous variants of the palette entries: Ember #ff7a57, Gold #ffc94d, Azure #6aa8ff, Fern #7fe08a, Orchid #c48cff, Rose #ff8fb0, Lagoon #4fe3cc, Chalk #f2ead8. They live render-side (`trailHex(paletteIndex)` in `src/render/theme.ts`), not in `src/sim`.
- Tests:
  - a food-only cell is exactly the base colour; a home-only cell is 60% of it;
  - a contested cell (sb = sa) is less saturated than an uncontested one;
  - an empty cell is all zeros;
  - colony 0 with palette colour 2 draws Azure-family pixels.

## Task 4: scents compete per cell (structural)

For the spec, in plain words: every cell holds each colony's scent. Laying scent weakens rivals' scent on that cell, so the colony that walks there more wins it. A cell changes owner only once the challenger is clearly stronger. Ants dislike rivals' scent, so they keep to their own roads unless they've taken the road over.

1. **Contest on deposit:** keep the current rule. Expose `foreignErasureFactor` in Settings as "Territory pressure" (0–1, default 0.5).
2. **Ownership with hysteresis:** new param `flipMargin` = 1.25, applied in `decayMarkers`'s owner recompute.
   - Keep the current owner unless another colony's max(home, food) ≥ flipMargin × the owner's, or the owner's has fallen to 0.
   - An unowned cell takes the strongest colony.
3. **Foreign scent deters:** new param `foreignAversion` = 0.35, Settings "Foreign scent aversion" (0–1).
   - In `senseMarkers`, a sample's score = own channel − foreignAversion × the strongest other colony's max(home, food) at that cell.
   - A score ≤ 0 doesn't count as found.
   - Direct sight of food or the nest ignores this.

Tests:
- **B's traffic flips a cell:** A's food scent = 1.0. B deposits 0.8 three times with no decay. Then A = 0.216 (1.0 × 0.6³) and B = 0.8, so the owner is B after recompute.
- **Hysteresis:** owner A at 0.6 and B at 0.7 → still A. B at 0.8 → B.
- **Aversion:** a B ant. Ahead: its own scent 0.3, plus A's 0.8 on the same cell. To the left: its own 0.2, no rival. It heads left. With `foreignAversion` 0, it heads straight.
- Aversion never blocks direct sight.
- Determinism: same seed, same checksum.

Guard: `npm run reach`. The contest row's colony B must still make at least 63 deliveries in minute 3 (75% of M2's 84). If it doesn't, lower the default `foreignAversion` (not below 0.15) and record that.
