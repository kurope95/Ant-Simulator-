# Milestone 0 (Skeleton) Implementation Plan — browser edition

> **For the implementing agent:**
> - Before Task 1, read `CLAUDE.md`, the design spec and the structure doc listed below.
> - Work through the tasks in order, one at a time. Tick the checkboxes as you go.
> - After every command, compare the real output with **Expected**. If they differ, stop and fix the cause before going on.
> - Never weaken, skip or delete an assertion to make a test pass.
> - Don't start Milestone 1 work.

**Goal:** A Chrome page that opens a sharp, DPI-aware WebGL2 canvas at native resolution. A camera-controlled test pattern, driven by a fixed 60 Hz simulation clock, sits under a DOM debug panel. Alongside that come headless PNG screenshots through Chrome, a Node bench CLI, a deterministic random-number generator and a `node:test` suite. There are no ants yet.

**Architecture:**
- One TypeScript build (`tsc`) to `dist/`, native ES modules, no bundler.
- `core` and `sim` are pure TypeScript with no DOM and no WebGL, so Node runs them for tests and the bench.
- `render` draws through one WebGL2 shader and batched triangle buffers; `ui` is a DOM overlay.
- Three entry points: interactive (Chrome), headless (Chrome, exact pixel size) and bench (Node CLI).

**Tech stack:** TypeScript 5.9.3, Node 24.13, Chrome 155, WebGL2, `node:test`. Two dev dependencies only (`typescript`, `@types/node`).

**Spec:**
- `docs/superpowers/specs/2026-10-25-ant-simulator-design.md` (*what*: this plan implements row M0 of §15),
- `docs/superpowers/specs/2026-10-25-ant-simulator-structure.md` (*where*, and every name).

## Global Constraints

- **No native executables.** Smart App Control blocks unsigned Windows programs. Only Node and Chrome run. Never install esbuild, Vite, Rollup native builds or TypeScript 7.
- **TypeScript 5.9.3**, `strict`, ES2022 modules, `moduleResolution: "Bundler"`, imports written with a `.js` extension so the emitted tree runs unchanged in Chrome and Node.
- **Layering:** `src/core` and `src/sim` never reference `document`, `window`, `canvas` or WebGL.
- **Randomness:** only `src/core/rng.ts`. Never `Math.random`.
- **Build folder:** `<repo>/dist`, gitignored. `node_modules/` and `captures/` are gitignored.
- **Naming:** files `snake_case.ts`; types `PascalCase`; functions and variables `camelCase`; constants `kPascalCase`.
- **Coordinates:** x right, **y down**; radians; positive angle turns clockwise on screen; heading 0 = +x.
- **Exit codes:** 0 success, 1 runtime failure, 2 usage error.
- **Commits:** after every task, with the message given. Never commit `dist/` or `node_modules/`.
- **Doubtful API calls:** check `tsconfig`/Node/Chrome reality rather than guessing; the fetched truth is `node --version`, `chrome --version` and the compiler output.

## Review Focus

These are the failure modes most likely to hit a real user that ordinary tests wouldn't reach, and the test that pins each one:

1. **Minimised window or zero-size canvas.** Expected: no crash, no NaN coordinates. Pinned by Task 8 "zero-size viewport" and the guard in Task 12's frame loop.
2. **Paths with spaces or non-ASCII characters.** The project path itself contains spaces. Expected: the screenshot tool still writes the PNG. Pinned by Task 11's test, which uses `fs.mkdtemp` under `%TEMP%`.
3. **Long stalls.** After the tab is frozen (debugger, window drag), the clock must not burst through a backlog. Pinned by Task 4 "long stall is capped".
4. **Bad input.** Expected: a specific error message, the usage text, and exit code 2. Pinned by Task 6 "errors are specific" and the Task 7 manual check.
5. **HiDPI.** At `devicePixelRatio` 2 the canvas backing store must be the full physical size, or everything is soft. Checked visually in Task 12 and by the screenshot's IHDR size in Task 11.

`tools/serve.mjs`:
```js
#!/usr/bin/env node
import { createServer } from "node:http";
import { readFile } from "node:fs/promises";
import { extname, resolve, sep } from "node:path";
import { pathToFileURL } from "node:url";

const kMime = {
  ".html": "text/html; charset=utf-8",
  ".js": "text/javascript; charset=utf-8",
  ".mjs": "text/javascript; charset=utf-8",
  ".css": "text/css; charset=utf-8",
  ".json": "application/json; charset=utf-8",
  ".png": "image/png",
  ".svg": "image/svg+xml",
  ".ico": "image/x-icon",
};

export function startServer({ root = process.cwd(), port = 8080 } = {}) {
  const base = resolve(root);
  const server = createServer(async (req, res) => {
    try {
      const url = new URL(req.url, "http://localhost");
      let path = decodeURIComponent(url.pathname);
      if (path.endsWith("/")) path += "index.html";
      const file = resolve(base, "." + path);
      if (file !== base && !file.startsWith(base + sep)) {
        res.writeHead(403).end("forbidden");
        return;
      }
      const body = await readFile(file);
      res.writeHead(200, {
        "content-type": kMime[extname(file).toLowerCase()] ?? "application/octet-stream",
        "cache-control": "no-store",
        "cross-origin-opener-policy": "same-origin",
        "cross-origin-embedder-policy": "require-corp",
      });
      res.end(body);
    } catch {
      res.writeHead(404).end("not found");
    }
  });
  return new Promise((resolvePromise, reject) => {
    server.once("error", reject);
    server.listen(port, "127.0.0.1", () => {
      const actual = server.address().port;
      resolvePromise({
        port: actual,
        url: `http://127.0.0.1:${actual}`,
        close: () => new Promise((done) => server.close(() => done())),
      });
    });
  });
}

if (process.argv[1] && pathToFileURL(process.argv[1]).href === import.meta.url) {
  const port = Number(process.env.PORT ?? 8080);
  startServer({ port }).then(({ url }) => console.log(`serving ${process.cwd()} at ${url}/`));
}
```

```ts
export function mix32(x: number): number {
  x = Math.imul(x ^ (x >>> 16), 0x7feb352d);
  x = Math.imul(x ^ (x >>> 15), 0x846ca68b);
  return (x ^ (x >>> 16)) >>> 0;
}

export function randU32(seed: number, uid: number, tick: number, stream: number): number {
  let h = mix32((seed ^ 0x9e3779b9) >>> 0);
  h = mix32((h ^ uid) >>> 0);
  h = mix32((h ^ (tick >>> 0)) >>> 0);
  h = mix32((h ^ stream) >>> 0);
  return h >>> 0;
}

export function randUnit(seed: number, uid: number, tick: number, stream: number): number {
  return randU32(seed, uid, tick, stream) / 4294967296;
}

export function randRange(seed: number, uid: number, tick: number, stream: number,
                          lo: number, hi: number): number {
  return lo + (hi - lo) * randUnit(seed, uid, tick, stream);
}
```

- [ ] **Step 3: Implement it with this algorithm.** The epsilon matters, because 1/120 + 1/120 is not exactly 1/60 in floating point.

```text
advance(frame, speed):
    if speed <= 0: return 0
    acc += max(frame, 0) * speed
    n = 0
    while acc + 1e-9 >= step and n < maxSteps: acc -= step; n += 1
    if n == maxSteps and acc >= step: acc = acc % step        # drop the backlog
    acc = max(acc, 0)
    return n
```
