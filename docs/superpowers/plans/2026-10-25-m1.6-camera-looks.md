### Issue 3: the camera
- **The touchpad can only zoom.** The wheel handler (`controller.ts` `onWheel`) always zooms at the cursor. On a laptop touchpad, two-finger scroll *and* pinch both arrive as wheel events, so both zoom.
- **Panning is awkward.** It works only with middle or right mouse drag (`onPointerDown`: `button !== 1 && button !== 2`), which is hard on a touchpad. Left-drag does nothing in Run mode.
- **No touch, keyboard panning or bounds.** There's no touch support, no keyboard panning, and nothing stops the world from being dragged off-screen.

### Issue 4: looks
- **Terrain is low-resolution.** It's baked once with Canvas2D at at most 0.5 texels per world unit (`terrain_texture.ts`) and stretched over the world. At normal zoom it's upscaled 3×, and at full zoom up to 32×, so it looks blurry.
- **Obstacles have no depth or edges.** Rocks are drawn as one flat disc per 4 u cell: no shading, no shadow, soft edges. Water is a flat colour.
- **Rocks barely show.** Themes are very dark: the meadow ground is `#0b100d` and rocks are `#2c3034`, so the two hardly contrast.

### Task 10: Map-style camera input
**Files:** `src/app/camera_input.ts` (new; pure helpers plus a `CameraInput` class with no DOM types; it takes plain objects), `src/render/camera.ts` (`setScaleLimits(min, max)`, `clampCenter(worldSize)`), `src/app/controller.ts` (delegate wheel, pointer and key handling), `styles.css` (`touch-action: none` on the canvas); tests `tests/app/test_camera_input.test.ts`, `tests/render/test_camera.test.ts`.

**Behaviour:**

| Input | Run screen | Builder screen |
|---|---|---|
| Left-drag | pan (starts after 4 px of movement) | the current tool; pans when using Select on empty ground, or while holding **Space** |
| Right or middle drag | pan | pan |
| Two-finger touchpad scroll | pan | pan |
| Touchpad pinch (wheel with `ctrlKey`) | zoom at the cursor | zoom at the cursor |
| Mouse wheel notch | zoom at the cursor, animated over about 120 ms | same |
| Touchscreen | one finger pans; two fingers pinch-zoom around their midpoint and pan | same, with two fingers only |
| WASD / arrow keys | pan at 900 CSS px/s while held | same |
| `+` / `−` | zoom ×1.25 at the view centre | same |
| Home | fit the world (existing) | same |
| Double-click | zoom ×2 at the point | — |

**Limits:**
- **Minimum zoom:** `0.6 × fitScale`, so you can't zoom far beyond the whole world.
- **Maximum zoom:** 16 px/u.
- **Panning bounds:** after every change, clamp the camera centre to `[0, worldW] × [0, worldH]`.

**Pinned helpers:**
```ts
export type WheelIntent = "zoom" | "pinch" | "pan";
export interface WheelLike { deltaX: number; deltaY: number; deltaMode: number; ctrlKey: boolean; timeStamp: number; }

// Chrome reports a touchpad pinch as ctrl+wheel; notched mice send whole multiples of 50+ with no x;
// touchpad scroll sends small or fractional deltas. Stay "pan" for 250 ms once a pan gesture starts.
export function classifyWheel(e: WheelLike, lastPanMs: number): WheelIntent {
  if (e.ctrlKey) return "pinch";
  if (e.deltaMode !== 0) return "zoom";                    // line or page mode: a mouse wheel
  if (e.timeStamp - lastPanMs < 250) return "pan";
  if (e.deltaX !== 0) return "pan";
  const notch = Number.isInteger(e.deltaY) && Math.abs(e.deltaY) >= 50 && e.deltaY % 50 === 0;
  return notch ? "zoom" : "pan";
}
// zoom factor:  pinch -> Math.exp(-e.deltaY * 0.01);  notch -> kZoomStep ** (-e.deltaY / 100)
// pan:          camera.panByScreen({ x: -e.deltaX * dpr, y: -e.deltaY * dpr })

export interface Touch2 { a: Vec2; b: Vec2; }              // device pixels
export function pinchStep(prev: Touch2, next: Touch2): { anchor: Vec2; factor: number; pan: Vec2 } {
  const mid = (t: Touch2) => ({ x: (t.a.x + t.b.x) / 2, y: (t.a.y + t.b.y) / 2 });
  const dist = (t: Touch2) => Math.hypot(t.a.x - t.b.x, t.a.y - t.b.y);
  const m0 = mid(prev), m1 = mid(next);
  return { anchor: m1, factor: dist(next) / Math.max(dist(prev), 1), pan: { x: m1.x - m0.x, y: m1.y - m0.y } };
}
// apply: camera.panByScreen(pan); camera.zoomAt(anchor, factor)
```

**Pointer rules:**
- Track pointers in a `Map<pointerId, Vec2>`.
- Use `clientX`/`clientY` differences multiplied by `devicePixelRatio`. Don't use `movementX`, which is unreliable for touch.
- When a second finger lifts, re-seed the last position from the remaining finger so the view doesn't jump.
- Show a `grab` cursor while hovering a pannable area, and `grabbing` while dragging.

**Tests:**
- `classifyWheel`: ctrl+wheel gives pinch; `deltaY` 100 with `deltaX` 0 gives zoom; `deltaY` 3.5 gives pan; `deltaX` 2 gives pan; within 250 ms of a pan gives pan.
- `pinchStep`: fingers moving from 100 px to 200 px apart give a factor of 2 with the anchor at the midpoint.
- `CameraInput`: a 100 px drag moves the centre by −100/scale; going from two fingers to one doesn't jump.
- `camera`: `clampCenter` keeps the centre inside the world; `setScaleLimits` clamps `zoomAt`.

**Manual check (you, on the laptop):** every row of the table above works.

### Task 12: Terrain shader with crisp ground, rocks, water, sand and mud
**Files:** `src/render/terrain_mask.ts` (new, pure: `obstacleMaskRgba(kind: Uint8Array): Uint8Array`), `src/render/terrain_shader.ts` (new: shader source plus a draw helper), `src/render/gl_renderer.ts`, `src/render/world_view.ts`, `src/render/theme.ts`; test `tests/render/test_terrain_mask.test.ts`.

**Replaces** the baked Canvas2D terrain (`terrain_texture.ts` is no longer used for the run view; delete it once nothing imports it).

**Mask texture:**
- RGBA8, one texel per obstacle cell (`world.obstacles.width × height`).
- Channels: R = rock, G = water, B = sand, A = mud, each 0 or 255.
- `LINEAR` filtering, `CLAMP_TO_EDGE`, `generateMipmap`.
- No premultiplied alpha.
- Rebuild it when the builder edits the terrain, in the same place `refreshTerrain` runs today.

**Drawing:** draw the world rectangle with the existing textured-quad vertex shader (`u_rect`, `v_uv` from 0 to 1, row 0 = world top) and this fragment shader:

```glsl
#version 300 es
precision highp float;
in vec2 v_uv;
uniform sampler2D u_mask;      // R rock, G water, B sand, A mud
uniform vec2 u_world;          // world size (u)
uniform float u_cell;          // obstacle cell (u), 4
uniform float u_time;          // seconds
uniform vec3 u_groundA, u_groundB, u_rockDark, u_rockLight, u_waterShallow, u_waterDeep, u_sand, u_mud;
out vec4 out_color;

float hash(vec2 p) { p = fract(p * vec2(123.34, 456.21)); p += dot(p, p + 45.32); return fract(p.x * p.y); }
float vnoise(vec2 p) {
  vec2 i = floor(p), f = fract(p), u = f * f * (3.0 - 2.0 * f);
  return mix(mix(hash(i), hash(i + vec2(1, 0)), u.x), mix(hash(i + vec2(0, 1)), hash(i + vec2(1, 1)), u.x), u.y);
}
float fbm3(vec2 p) { return 0.5 * vnoise(p) + 0.25 * vnoise(p * 2.03 + 17.1) + 0.125 * vnoise(p * 4.11 + 31.7); }
float cover(float m, float soft) { return smoothstep(0.5 - soft, 0.5 + soft, m); }

void main() {
  vec2 w = v_uv * u_world;                                   // world position
  float px = max(fwidth(w.x), fwidth(w.y));                  // world units per screen pixel
  float soft = clamp(px / (2.0 * u_cell), 0.01, 0.35);       // ~1 px anti-aliased edges
  float detail = smoothstep(1.2, 0.25, px);                  // fine grain only when zoomed in

  vec2 warp = (vec2(fbm3(w * 0.05), fbm3(w * 0.05 + 23.0)) - 0.4375) * 3.4;   // organic edges, ±1.5 u
  vec2 muv = (w + warp) / u_world;
  vec4 m = texture(u_mask, muv);
  float rock = cover(m.r, soft), water = cover(m.g, soft), sand = cover(m.b, soft), mud = cover(m.a, soft);

  vec3 col = mix(u_groundA, u_groundB, smoothstep(0.3, 0.7, fbm3(w * 0.0035)));
  col *= 0.93 + 0.14 * mix(0.5, vnoise(w * 0.8), detail);

  if (sand > 0.0) {
    float ripple = 0.5 + 0.5 * sin(w.x * 0.45 + w.y * 0.12 + fbm3(w * 0.04) * 7.0);
    col = mix(col, u_sand * (1.0 + 0.15 * (ripple - 0.5) * detail), sand * 0.8);
  }
  if (mud > 0.0) col = mix(col, u_mud * (0.8 + 0.35 * fbm3(w * 0.15)), mud * 0.85);

  vec2 toLight = vec2(-0.7071, -0.7071);                     // light from the top-left
  float shade = cover(textureLod(u_mask, muv + toLight * 6.0 / u_world, 1.5).r, 0.3);
  col *= 1.0 - 0.38 * shade * (1.0 - rock) * (1.0 - water); // rock shadows fall bottom-right

  if (water > 0.0) {
    float depth = smoothstep(0.5, 1.0, textureLod(u_mask, muv, 2.5).g);
    vec3 wc = mix(u_waterShallow, u_waterDeep, depth);
    wc += vec3(0.05, 0.07, 0.07) * smoothstep(0.55, 0.75, fbm3(w * 0.07 + vec2(u_time * 0.12, u_time * 0.08)));
    float foam = smoothstep(0.38, 0.5, m.g) * (1.0 - smoothstep(0.5, 0.66, m.g));
    col = mix(col, mix(wc, vec3(0.78, 0.88, 0.86), foam * 0.4), water);
  }

  if (rock > 0.0) {
    vec2 t = vec2(u_cell) / u_world;                         // one cell in uv
    // textureLod, not texture: implicit derivatives are undefined inside this branch
    float gx = textureLod(u_mask, muv + vec2(t.x, 0), 0.0).r - textureLod(u_mask, muv - vec2(t.x, 0), 0.0).r;
    float gy = textureLod(u_mask, muv + vec2(0, t.y), 0.0).r - textureLod(u_mask, muv - vec2(0, t.y), 0.0).r;
    vec3 n = normalize(vec3(-gx, -gy, 0.55));                // edges tilt outward
    float lit = clamp(dot(n, normalize(vec3(toLight, 0.9))), 0.0, 1.0);
    float stone = 0.65 * fbm3(w * 0.22) + 0.35 * mix(0.5, vnoise(w * 1.1), detail);
    vec3 rc = mix(u_rockDark, u_rockLight, 0.25 + 0.75 * lit) * (0.82 + 0.3 * stone);
    rc *= 1.0 - 0.22 * smoothstep(0.6, 0.68, vnoise(w * 0.3));                  // cracks
    col = mix(col, rc, rock);
  }
  out_color = vec4(col, 1.0);
}
```

### Task 13: Anthills that look like mounds
**Files:** `src/render/sprite_atlas.ts` (the nest frame painter), `src/render/nest_layer.ts`.

Paint the nest frame at 256×256 px or more with this layering, keeping the atlas API unchanged:

```ts
// cx, cy, r in atlas pixels; colony = CSS colour string; rnd(i) = deterministic 0..1 from (colony id, i)
function paintAnthill(ctx: CanvasRenderingContext2D, cx: number, cy: number, r: number, colony: string, rnd: (i: number) => number): void {
  const TAU = Math.PI * 2;
  for (let i = 0; i < 90; i++) {                               // 1. excavated soil scattered around
    const a = rnd(i) * TAU, d = r * (0.95 + 0.6 * Math.sqrt(rnd(i + 500)));
    ctx.fillStyle = `rgba(120, 92, 62, ${0.35 + 0.4 * rnd(i + 1300)})`;
    ctx.beginPath(); ctx.arc(cx + Math.cos(a) * d, cy + Math.sin(a) * d, r * (0.015 + 0.03 * rnd(i + 900)), 0, TAU); ctx.fill();
  }
  let g = ctx.createRadialGradient(cx + r * 0.12, cy + r * 0.16, r * 0.2, cx + r * 0.12, cy + r * 0.16, r * 1.08);
  g.addColorStop(0, "rgba(0,0,0,0.45)"); g.addColorStop(1, "rgba(0,0,0,0)");   // 2. shadow, bottom-right
  ctx.fillStyle = g; ctx.beginPath(); ctx.arc(cx + r * 0.12, cy + r * 0.16, r * 1.08, 0, TAU); ctx.fill();
  g = ctx.createRadialGradient(cx - r * 0.3, cy - r * 0.35, r * 0.1, cx, cy, r);  // 3. mound lit from top-left
  g.addColorStop(0, "#a07c52"); g.addColorStop(0.55, "#7a5a3a"); g.addColorStop(1, "#4a3523");
  ctx.fillStyle = g; ctx.beginPath(); ctx.arc(cx, cy, r, 0, TAU); ctx.fill();
  for (let i = 0; i < 160; i++) {                              // 4. grain on the mound
    const a = rnd(i + 2000) * TAU, d = r * 0.92 * Math.sqrt(rnd(i + 2500));
    ctx.fillStyle = rnd(i + 3000) < 0.5 ? "rgba(40,28,18,0.35)" : "rgba(190,160,120,0.25)";
    ctx.fillRect(cx + Math.cos(a) * d, cy + Math.sin(a) * d, r * 0.018, r * 0.018);
  }
  ctx.globalAlpha = 0.7; ctx.strokeStyle = colony; ctx.lineWidth = r * 0.07;   // 5. colony ring at the foot
  ctx.beginPath(); ctx.arc(cx, cy, r * 0.97, 0, TAU); ctx.stroke(); ctx.globalAlpha = 1;
  g = ctx.createRadialGradient(cx, cy, 0, cx, cy, r * 0.22);                    // 6. entrance hole
  g.addColorStop(0, "#0b0705"); g.addColorStop(0.7, "#1d130c"); g.addColorStop(1, "rgba(29,19,12,0)");
  ctx.fillStyle = g; ctx.beginPath(); ctx.ellipse(cx, cy, r * 0.22, r * 0.16, 0, 0, TAU); ctx.fill();
}
```
